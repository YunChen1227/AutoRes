1. 上传数据

CSV 需含 Input Length / Input_Length 与 Concurrency 两列（维度）； 其他指标列名会自动映射到 to_csv.py 规范 schema。启动命令直接粘贴，支持 # 注释行与反斜杠续行。
默认「单机 / 分布式」；若命令里出现 disaggregation / kv-transfer-config 等 PD 参数，会自动切到「PD 分离」， 需分别填写 prefill、decode（router 可选）。
result.csv（一次测试一份，PD 也是打整体服务的一份）

2. bench（压测）参数

bench 框架与上面的 server 框架相互独立（sglang bench 可打 vllm server，反之亦然）。 上传 CSV 后会按 spec decoding 列是否有值自动识别：仅 vLLM 列有值→vllm，仅 SGLang 列有值→sglang； 两者都有 / 都无则需手选。
是否 flush cache 无法从 CSV 推断，必须手动选择（flush=冷启动无前缀命中，不 flush=复用缓存，结果差异大）。

3. 填写元信息

这些字段无法从 CSV / 启动命令推断，需手工填写。其中框架决定用哪套启动参数提取规则与默认值回填。
